# 📇 Lista de Contatos

Projeto desenvolvido como exercício prático, para treinas conceitos de React como componentização, estados globais e locais, eventos, navegação entre páginas e componentes. 
 
## ✨ Funcionalidades
 
- Cadastro e edição de contatos
- Classificação por tipo: Amigo, Trabalho, Família ou Outro
- Máscara automática para número de telefone

## 🚀 Tecnologias utilizadas
 
- React
- TypeScript
- Redux
- Styled Components
- React Router DOM
- ESLint / Prettier

## 📦 Como rodar o projeto
 
```bash
# Clone o repositório
git clone https://github.com/aarielmartins/Projeto---Lista_Contatos.git
 
# Acesse a pasta
cd Projeto---Lista_Contatos
 
# Instale as dependências
npm install
 
# Rode o projeto
npm start
```
